# Security policy

## Reporting a vulnerability

Please report security issues privately to the repository owner. Do not open a public issue with
credentials, tokens, session cookies, personal data, or a working exploit.

## Data handling

- Secrets are loaded from environment variables only.
- Raw payloads must not contain authentication headers or private account data.
- Public contact information may be collected only when it is part of the opportunity itself.
- The project does not automate outreach or application submission.
